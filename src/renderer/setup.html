Set up the overlay

Three things this install needs to know. You can change them later from the tray icon.

Prices are looked up against this league on poe.ninja, the currency exchange and the trade site. A name that doesn't match the one you're playing leaves everything unpriced.
PoE2's log, read to detect which map you're in so drops are grouped per map. Leave it empty to run without map detection.
Sent to GGG in the User-Agent when pricing rare items, so they can reach you about the requests your machine makes. Leave it blank and no contact address is sent at all.
