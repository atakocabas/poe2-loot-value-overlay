Settings

These apply the moment you save — the overlay doesn't restart. The league, Client.txt path and contact email live under Setup… instead, because changing those does.

Hotkeys

Click a combination to change it, then press the keys you want. Every hotkey needs at least one of Ctrl, Alt or Shift — a bare key would be taken from Path of Exile 2 as well, including from its chat box. Esc cancels; Backspace unbinds.

The panel normally shows only the last item you copied. This opens the whole list — filters, Export, and the per-row Edit button — and makes the overlay clickable so you can use them. Press it again to go back. Nothing else ever changes the panel's size.
Re-reads whatever the clipboard already holds. Copying an item with Ctrl+C is picked up on its own; this is for a second look at the same item, which the automatic watcher skips.

Overlay

The panel sits above everything on the primary display, so without this it covers your browser and Discord when you alt-tab. Turn it off if you play windowed on a second monitor and want the panel permanently visible; that also skips a small background helper process.
Grace period before hiding. The game briefly hands the foreground to Windows during loading screens and fullscreen switches, and without a delay the panel blinks off on every zone.

A share of your screen height rather than a pixel count, so a size that fits one monitor doesn't run off the bottom of another.

Which side of the screen the panel sits against. The bottom-right is also where the game puts the minimap and the flask row, so how much they overlap depends on your UI scale and resolution. The panel stays along the bottom either way.

Display

Only affects what you read — values are always stored in chaos, so changing this never rewrites anything. Automatic shows an item priced off the trade site in the currency its cheapest listing was asking, so the row reads the way the market does; anything else — poe.ninja prices, the map total — uses divine, chaos or exalted by size.

Trade search

The price this app reports is a market floor — what you could sell into today — so it counts Instant Buyout listings by default. An in-person listing needs the seller to answer a whisper and invite you, which is not a price you can transact against on demand. This is the usual reason a number here disagrees with the trade site: widening it finds more comparables on thin bases, at the cost of pricing against listings nobody can simply buy. These are GGG's own options, and View search reopens whichever one produced the price.
Prices come from the cheapest matching listings, so a listing with no asking price has no number to contribute — it can only take a slot a real price would have filled. Buyable now is what the trade site does by default. Widening this finds more comparables on thin bases, at the cost of counting listings you can't simply buy.
A waystone's affixes are monster-difficulty mods, and nobody lists the exact set yours has — one real T15 matched 0 listings on its six affixes and 3453 on the reward block those affixes add up to. So a waystone is searched on Item Rarity, Pack Size, Monster Rarity, Waystone Drop Chance, Revives and Monster Effectiveness instead, each of them as a floor. Unticking this searches the affixes instead, which is what the app did before.
How far the search reaches past the waystone's own numbers, as a percentage of them. At 90 a map printing 24% Item Rarity asks for 21+, and one printing 13% Monster Effectiveness asks for 11+. At 100 the only matches are waystones strictly better than yours, which prices something you don't have; lower finds more comparables and prices a slightly rougher match.
Turn this on in Path of Exile 2 under Options → UI. It makes the game print each mod's tier when you copy an item, and the app uses those tiers to decide which mods to leave out when nothing is listed carrying the whole set — so it drops a weak affix rather than the roll that makes the item worth something. Without it pricing still works, just without that preference. This is a game setting, so there's nothing to save here.
