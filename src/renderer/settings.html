Settings

These apply the moment you save — the overlay doesn't restart. The league, Client.txt path and contact email live under Setup… instead, because changing those does.

Hotkeys

Click a combination to change it, then press the keys you want. Every hotkey needs at least one of Ctrl, Alt or Shift — a bare key would be taken from Path of Exile 2 as well, including from its chat box. Esc cancels; Backspace unbinds.

Switches the panel between click-through and interactive without changing its size. Showing the full list already does this for you; this is for the times you want one without the other.
Opens or closes a map session by hand, for when zone detection has the wrong idea — or when Client.txt isn't being read at all.
Re-reads whatever the clipboard already holds. Copying an item with Ctrl+C is picked up on its own; this is for a second look at the same item, which the automatic watcher skips.

Overlay

The panel sits above everything on the primary display, so without this it covers your browser and Discord when you alt-tab. Turn it off if you play windowed on a second monitor and want the panel permanently visible; that also skips a small background helper process.
Grace period before hiding. The game briefly hands the foreground to Windows during loading screens and fullscreen switches, and without a delay the panel blinks off on every zone.
ms
The list holds every drop you've recorded, so a narrow panel truncates item names and wraps the editor's roll boxes onto a second line.
px
A share of your screen height rather than a pixel count, so a size that fits one monitor doesn't run off the bottom of another.
% of screen height
Which side of the screen the panel sits against. The bottom-right is also where the game puts the minimap and the flask row, so how much they overlap depends on your UI scale and resolution. The panel stays along the bottom either way.

Display

Only affects what you read — values are always stored in chaos, so changing this never rewrites anything. Automatic uses divine for anything worth at least one and exalted below that, which is how players actually quote prices.
